# YBM Podcast Transcripts

Transcripts of Rafizi Ramli's long-form podcast (*Yang Bakar Menteri* / *Yang Berhenti Menteri* / *YBM*), built with the [same structured-archive approach](https://github.com/ChatPRD/lennys-podcast-transcripts) as Lenny's Podcast Transcripts.

Source playlist: https://www.youtube.com/playlist?list=PLqJKhYZQ8r9Uz3IPEh0lXpF17w3LQK62N

Only full episodes (30+ minutes) are included. Short teasers, clip highlights, and quote-card snippets from the same playlist are excluded.

## Structure

Each episode lives in `episodes/<publish-date>-<title-slug>/` with four files:

- `raw.md` -- a close-to-verbatim transcript straight from the audio, with timestamps and speaker labels. Filler words are lightly cleaned up but nothing is paraphrased or summarized.
- `interview.md` -- a polished newspaper-style Q&A rewrite, kept in the original mixed English/Bahasa Melayu -- closest to how the conversation was actually spoken.
- `interview-en.md` -- the same rewrite, fully translated into English.
- `interview-ms.md` -- the same rewrite, fully translated into Bahasa Melayu.

All four files share the same YAML frontmatter (title, video ID, YouTube URL, publish date, duration, view count, hosts, guests); the three interview versions also carry an AI-generated summary and topic tags. Pick whichever version suits your use case.

`data/manifest.json` is the full episode index (metadata only, no transcript text) used to drive the pipeline.

## Accuracy note

Transcripts and rewrites are generated by an AI model (Gemini) listening directly to the source audio. They are not manually verified against the original recording. Code-switching between Bahasa Melayu and English is preserved rather than translated, but errors, mishearings, or misattributed speaker turns are possible, especially in cross-talk. Treat `raw.md` as the closer-to-source reference and `interview.md` as an editorial rewrite built on top of it.

## Pipeline

Requires a `GEMINI_API_KEY` environment variable and Python 3.

```bash
pip install -r requirements.txt

# Refresh the episode manifest from the playlist (only episodes >= 30 min)
python scripts/build_manifest.py

# Process one episode
python scripts/transcribe_episode.py <video_id>

# Process everything not yet done (or pass specific video IDs)
python scripts/batch_process.py
```

Each episode's audio is read directly from its YouTube URL via the Gemini API (no local download). Long episodes are split into 20-minute windows to stay under the model's output limit; each window is transcribed, then rewritten, then the two are stitched back together per episode.
